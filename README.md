# 짱디터 (JJangditer)

서버 설치 작업을 **위에서 아래로 순서대로** 진행하면서, 각 항목의 *현재 값 / 설정할 값* 을 적어두고
명령어·표는 바로 복사해 쓰는 **화면 우측 도킹형 체크리스트 에디터**입니다.

---

## 1. 실행 / 배포

### 직원에게 줄 파일 — 딱 하나
```
dist\짱디터-1.3.0.exe      (약 1 MB)
```
설치 프로그램이 아니라 **그냥 실행하는 파일**입니다. 설치·레지스트리 등록이 없고,
지우고 싶으면 exe 와 `%APPDATA%\JJangditer` 만 지우면 흔적이 남지 않습니다.

윈도우에 들어 있는 **Edge WebView2** 를 화면 표시에 사용합니다.
윈도우 10/11 에는 기본으로 깔려 있어 직원 PC 에 따로 설치할 것이 없습니다.

처음 실행하면 화면 파일을 `%LOCALAPPDATA%\JJangditer` 에 한 번 풀어둡니다(약 100KB).

### 개발 / 다시 빌드
```powershell
npm run dist          # 배포용 exe 만들기 (윈도우 기본 C# 컴파일러 사용)
npm run icon          # 아이콘 다시 생성 (python + Pillow)
npm run template      # 내장 템플릿을 .jjt 로 추출
npm run release -- --to "\서버\공유\짱디터"   # 배포 + latest.json
```

빌드에 **설치해야 하는 개발 도구가 없습니다.** 윈도우에 기본 포함된
`csc.exe`(.NET Framework 4.8 컴파일러)로 만들고, WebView2 SDK 는 DLL 파일 3개를
처음 한 번 내려받아 `host/lib` 에 둡니다.

> `npm start` 는 예전 Electron 판으로 띄우는 개발용 경로입니다.
> 화면(HTML/CSS/JS)은 두 방식이 같은 파일을 쓰므로 UI 수정은 어느 쪽에서든 확인할 수 있습니다.

## 2. 화면 동작

| 동작 | 방법 |
|---|---|
| 우측 고정 / 자동 숨김 전환 | 제목줄의 **📌** 버튼 (또는 트레이 아이콘 우클릭) |
| 숨겨진 상태에서 다시 꺼내기 | 화면 **우측 끝 파란 띠**에 마우스를 올리기 |
| 어디서든 열기/닫기 | **Alt + Shift + J** |
| 폭 조절 | 패널 **왼쪽 테두리**를 좌우로 드래그 |
| 다른 모니터로 옮기기 | **제목줄을 끌어다 놓으면** 그 모니터 우측에 다시 도킹됩니다<br>제목줄 **더블클릭** 또는 `보기` → `다음 모니터로 이동` 으로도 됩니다 |
| 트레이로 숨기기 | 제목줄 **－** / 종료는 **✕** |

옮긴 모니터는 기억했다가 다음에 켤 때도 그 자리에 뜹니다. 띠도 함께 따라갑니다.

숨으면 패널 창은 완전히 사라지고 화면 우측 끝에 **9px 파란 띠**만 남습니다.
오른쪽에 모니터가 더 있어도 옆 화면으로 삐져나오지 않습니다.

다음 경우에는 일부러 숨지 않습니다 — 입력란에 커서가 있을 때, 메뉴·대화상자가 열려 있을 때,
패널이 활성 창일 때(다른 창을 클릭하면 그때 숨습니다).

## 3. 작업 화면 / 설정 화면

상단 **[작업]** 버튼(또는 `Ctrl+D`)으로 두 화면을 오갑니다.

| | 보이는 것 |
|---|---|
| **작업 화면** (기본) | 값 입력칸과 **완성된 글·명령**만. 변수 키, 행 조작 버튼, 드래그 손잡이, 추가 버튼은 감춤 |
| **설정 화면** | 전부. 항목 추가·삭제, 순서 바꾸기, 변수 키 지정 등 **틀을 고칠 때** 사용 |

`{{키}}` 가 들어간 글·명령은 작업 화면에서 **치환이 끝난 결과만** 보여줍니다.
공지 문자처럼 "최종 결과만 보고 복사하면 되는" 내용이 한눈에 들어옵니다.
원문을 고치려면 설정 화면으로 넘어가세요.

## 4. 메뉴

상단 메뉴 바에서 모든 기능을 찾을 수 있습니다.

| 메뉴 | 주요 항목 |
|---|---|
| **파일** | 새 탭(템플릿), 불러오기, 내보내기(.jjt/.jjw/.md), 지금 저장, 데이터 폴더, 종료 |
| **편집** | 항목·명령·글·표·섹션 추가, 전체 복사, 체크 모두 해제, 새 서버용 복제, 탭 이름/삭제 |
| **찾기** | 찾아 바꾸기, 미완료만 보기, 다음 할 항목 |
| **보기** | 작업/설정 화면, 현재값·변수키 표시, 테마, 고정, 모니터 이동, 숨김 지연 |
| **도구** | 업데이트 확인·설정, 자원 절약 모드 |
| **도움말** | 단축키, 팁, 버전 |

### 찾아 바꾸기 (`Ctrl+H`)
기존 샘플을 다른 현장용으로 바꿀 때처럼 **한 번에 치환**합니다.
찾을 내용을 입력하면 **몇 곳에서 찾았는지 바로 알려주고**, 탭 이름·표 안까지 모두 바꿉니다.
`모든 탭에서 바꾸기` 를 켜면 전체 탭이 대상입니다.

## 5. 항목 종류

| 종류 | 단축키 | 용도 |
|---|---|---|
| **섹션** | `Ctrl+Shift+N` | `1. 네트워크 설정` 처럼 단계를 묶는 제목. 접기/펼치기, 단계별 진행률 |
| **항목** | `Ctrl+N` | 항목명 + *현재값* + *설정할 값* + 메모. 값 옆 **⧉** 로 복사 |
| **명령어** | `Ctrl+K` | 여러 줄 명령 블록. **복사** 버튼으로 한 번에 복사 |
| **글** | `Ctrl+M` | 공지 문자처럼 여러 줄 글을 그대로. **복사** 버튼으로 전체 복사 |
| **표** | `Ctrl+T` | 자유 크기 표. 셀·행·열·전체 단위로 복사 |

긴 글·명령은 **[⤢ 크게]** 를 누르면 패널 전체로 펼쳐져 편하게 고칠 수 있습니다
(`Ctrl+Enter` 저장, `Esc` 닫기).

체크박스를 켜면 완료 처리되고, 아직 안 한 항목 중 **맨 위 항목**에 주황색 표시가 붙습니다.
상단 **다음 ▾** 을 누르면 그 항목으로 이동합니다.

## 6. 글 블록 — txt 쓰기 · 열 편집 · 찾기

탭 종류는 **하나**입니다. 체크리스트 안에 **글 블록**(`＋ 글`, `Ctrl+M`)을 넣으면
그 자리가 곧 txt 입니다.

블록 아래에 버튼 세 개가 있습니다.

| 버튼 | 하는 일 |
|---|---|
| **🔎 찾기** | 이 글에서 찾기 (`Ctrl+F` 와 같음). 편집기가 열리면서 찾기 줄이 바로 나옵니다 |
| **⤢ 전체 편집** | 패널 **전체 크기**로 펼쳐서 편집 |
| **복사** | 변수가 채워진 상태로 전체 복사 |

블록 자체도 길면 **스크롤**되고, 오른쪽 아래 모서리를 끌어 높이를 늘릴 수 있습니다.

모서리를 끌어 **패널 아래 끝까지 내리면 테두리가 파랗게 바뀌고**,
그 상태에서 손을 놓으면 **패널 높이에 딱 맞게** 커집니다 (윈도우의 화면 끝 맞춤과 같은 방식).

마우스로 끌지 않고 바로 정하려면 줄을 **우클릭 → `↕ 높이` ▶** 에서 고르세요.

```
● 자동 (내용에 맞춤)
○ 작게 160px   ○ 보통 320px   ○ 크게 560px   ○ 아주 크게 900px
⤢ 패널 높이에 맞추기
```

정한 높이는 기억합니다.

```
＋ 항목   ＋ 명령   ＋ 글   ＋ 표   ＋ 섹션
                    └── 여기가 txt. [⤢ 크게] 로 전체 편집기
```

편집기에서 할 수 있는 것

| 하는 일 | 방법 |
|---|---|
| 찾기 / 바꾸기 | **`Ctrl+F`** / **`Ctrl+H`** 또는 아래 `🔎 찾기` 버튼 |
| 열 편집 켜기/끄기 | **`Alt+C`** (한 번 더 누르면 해제) 또는 아래 `열 편집` 버튼 |
| 열 편집 (모드 없이) | **Alt 를 누른 채 드래그** |
| 글에서 찾기 | **`Ctrl+F`** — 찾은 곳 전부 주황색 표시, `F3`/`Shift+F3` 로 이동 |
| 찾아 바꾸기 | **`Ctrl+H`** — `바꾸기` / `모두 바꾸기` |
| 줄 단위 일괄 작업 | 아래 `줄 도구` 버튼 |
| 텍스트 파일로 저장 | **`Ctrl+S`** 또는 `파일로 저장` (연 파일이 있으면 덮어쓰기) |
| 되돌리기 / 다시 | `Ctrl+Z` / `Ctrl+Y` |
| 닫기 | `Esc` (내용은 그대로 남습니다) |

### 열 편집 (UltraEdit 의 칼럼 모드)

```
websvr1   192.168.0.11   WEB     ← IP 칸만 세로로 선택
websvr2   192.168.0.12   WAS
websvr3   192.168.0.13   DB 
```

| 키 | 결과 |
|---|---|
| 글자 입력 | 선택한 칸이 **모든 줄에서** 동시에 바뀝니다 |
| `Backspace` / `Delete` | 선택한 칸을 모든 줄에서 지웁니다 |
| `Ctrl+C` / `Ctrl+X` | 네모 영역만 줄 단위로 복사 / 잘라내기 |
| `Ctrl+V` | 줄 수가 맞으면 **줄마다 하나씩** 들어갑니다 |
| `Esc` | 선택 해제 |

줄이 짧아 그 칸이 없으면 공백으로 채워 칸을 맞춥니다.
탭 문자도 4칸 기준으로 계산해 칸이 어긋나지 않습니다.

### 파일 내에서 찾기 (`Ctrl+Shift+F`)

폴더 하나를 통째로 뒤져서 그 글자가 들어간 파일과 줄을 찾아줍니다.
울트라에디터의 `파일 내에서 찾기` 와 같은 기능입니다.

`찾기` 메뉴 → **`파일 내에서 찾기…`**

| 칸 | 설명 |
|---|---|
| 찾기 | 찾을 글자 |
| 파일 형식 | `*.txt` 처럼. `*.txt;*.log` 로 여러 개도 가능 |
| 디렉토리 | 찾을 폴더 (`…` 버튼으로 고르기) |
| 하위 폴더까지 찾기 | 켜면 아래 폴더들까지 전부 |
| 대/소문자 구분 | |

결과는 **새 탭**에 이렇게 정리되어 열립니다.

```
찾기 : "13,500,000"
폴더 : D:_작업자_일일업무일지  (하위 폴더 포함)
형식 : *.TXT

D:_작업자_일일업무일지61028.TXT
       2 : 금액 13,500,000 원 지급

D:_작업자_일일업무일지61029.TXT
       2 : 합계 13,500,000

파일 2개에서 2곳을 찾았습니다.
```

찾는 동안 위쪽에 **진행 상황**이 표시되고(살펴본 파일 수 · 찾은 곳 수 · 현재 파일),
**취소** 버튼으로 중단할 수 있습니다. 찾기는 뒤에서 도니까 창이 멈추지 않습니다.

결과에서 **파일 경로 줄 아래의 내용 줄을 더블클릭**하면 그 파일이 열립니다.
파일마다 인코딩(ANSI/UTF-8)을 알아서 판별하므로 섞여 있어도 한글이 깨지지 않습니다.

### 줄 도구

줄 끝/앞 공백 지우기, 빈 줄 지우기, 번호 매기기, 가나다 정렬,
중복 줄 지우기, **탭을 공백 4칸으로**, 전체 복사.

### 텍스트 파일 열기

`파일` → `텍스트 파일 열기…` 또는 `＋` 탭 → `열기…` → `텍스트 파일`.
파일 하나가 **글 블록 하나를 가진 새 탭**으로 열리고, 바로 편집기가 뜹니다.
`Ctrl+S` 를 누르면 **원래 파일에 덮어쓰기** 됩니다.

### 글자 인코딩 — 한글이 깨지지 않도록

울트라에디터·메모장에서 만든 txt 는 **ANSI(CP949)** 인 경우가 많습니다.
짱디터는 파일을 열 때 **인코딩을 자동으로 알아냅니다.**

| 알아내는 것 | 방법 |
|---|---|
| UTF-8 BOM / UTF-16 LE / UTF-16 BE | 파일 앞의 BOM 표시로 판별 |
| UTF-8 | BOM 이 없으면 UTF-8 로 엄격하게 읽어보고 성공하면 UTF-8 |
| ANSI (CP949) | UTF-8 로 읽히지 않으면 한글 윈도우 기본 코드페이지로 |

편집기 아래쪽에 지금 인코딩이 표시됩니다(ANSI 면 주황색). 그 버튼을 누르면 바꿀 수 있습니다.

**저장할 때는 열었던 인코딩 그대로 씁니다.** 울트라에디터에서 만든 ANSI 파일을
짱디터로 고쳐 저장해도 울트라에디터에서 그대로 열립니다.
UTF-8 로 바꾸고 싶으면 인코딩 버튼에서 `UTF-8` 을 고른 뒤 `파일 저장` 을 누르세요.

## 7. 표

**＋ 표** 를 누르면 격자가 나옵니다. 마우스로 훑어 `3×3`, `4×5` 처럼 고르거나,
아래쪽에 숫자를 직접 넣어 만들 수 있습니다 (최대 60행 × 20열).

### 복사하는 방법

| 무엇을 | 어떻게 |
|---|---|
| 셀 하나 | 셀을 **더블클릭** |
| 행 하나 | 왼쪽의 **행 번호**(1, 2, 3…) 클릭 |
| 열 하나 | 위쪽의 **열 문자**(A, B, C…) 클릭 |
| 표 전체 | 좌상단 **⧉** 또는 **표 복사** 버튼 → 탭 구분(엑셀에 그대로 붙여넣기) |
| 마크다운 표 | **MD** 버튼 → 메신저·위키용 |

셀에서 **우클릭** 하면 행/열 삽입·삭제까지 한 번에 할 수 있습니다.
**Enter** 를 누르면 아래 칸으로 이동하고, 마지막 행에서는 행이 하나 늘어납니다.
아래 **행＋ 행－ 열＋ 열－** 로 크기를 바꾸고, **머리글** 로 첫 행을 제목 줄로 지정합니다.

표 안에서도 `{{키}}` 변수가 그대로 동작합니다(복사할 때 값으로 치환됨).

## 8. 변수 치환 ( `{{키}}` )

항목에 **키**를 지정해두면, 명령어·표 안에서 `{{키}}` 로 그 값을 가져다 씁니다.

```
항목:  IP 주소        키: ip         설정값: 192.168.10.101
항목:  인터페이스     키: iface      설정값: ens192
항목:  Prefix         키: prefix     설정값: 24

명령어:
  nmcli con mod "{{iface}}" ipv4.addresses {{ip}}/{{prefix}}
```

명령어 아래에 **값이 적용된 실제 명령**이 주황색 미리보기로 나오고,
**복사** 버튼은 항상 *치환된 상태*로 복사합니다.
→ 서버마다 IP 와 호스트명만 바꾸면 모든 명령어가 자동으로 맞춰집니다.

키 입력란은 값이 있을 때만 보입니다. 항상 보이게 하려면 ☰ → `변수 키 입력란 항상 표시`.

## 9. 탭 (작업/상태 구분)

### 탭을 닫을 때

| 상황 | 동작 |
|---|---|
| 연 파일을 고쳤는데 저장 안 함 | **저장할까요?** `예 / 아니오 / 취소` 를 물어봅니다 |
| 연 파일이고 바뀐 것 없음 | 그냥 닫습니다 (파일은 그대로이니 다시 열면 됩니다) |
| 짱디터 안에만 있는 내용 | 없어진다고 한 번 확인합니다 |


- 탭 하나 = 서버 하나 또는 작업 하나
- **＋** 를 누르면 이렇게 나옵니다

```
＋ 새로 만들기          빈 탭
📂 열기…               txt · jjt · jjw
─────────────────────
📋 템플릿          ▶   → Linux 서버 설치 / Windows 서버 설치 / DR 복구 훈련 / 빈 작업
⏱ 최근 항목        ▶   → 최근에 연 파일과 쓴 템플릿
```

`▶` 에 마우스를 올리면 옆으로 펼쳐집니다.
최근 항목은 **최근에 연 텍스트 파일**과 **최근에 쓴 템플릿**을 12개까지 기억합니다.

- **더블클릭** 이름 변경 · **우클릭** 탭 메뉴 · **드래그** 순서 변경
- 탭 이름 옆 숫자는 `완료/전체`, 전부 끝나면 초록색

새 서버를 시작할 때는 탭 우클릭 → **복제 (체크 해제)** 를 쓰면
같은 절차를 그대로 가진 새 탭이 생깁니다. IP · 호스트명만 고쳐 쓰면 됩니다.

## 10. 저장 / 공유

자동 저장됩니다. 저장 위치:
```
%APPDATA%\JJangditer\workspace.json     (내용)
%APPDATA%\JJangditer\prefs.json         (창 설정)
```

| 메뉴 (☰) | 결과 |
|---|---|
| 현재 탭 내보내기 | `.jjt` — 탭 하나. 동료 전달용 |
| 전체 내보내기 | `.jjw` — 모든 탭 |
| 파일 불러오기 | `.jjt` / `.jjw` 를 **새 탭으로 추가** (기존 탭 유지, 여러 개 선택 가능) |
| 텍스트(.md)로 저장 | 작업 보고서용 마크다운 (명령어·표는 치환된 상태) |
| 현재 탭 전체 복사 | 같은 내용을 클립보드로 |

**마지막으로 저장하거나 불러온 폴더를 기억**했다가 다음에 그 폴더부터 엽니다.
(처음에는 `내 문서`)

### 내용이 날아가지 않도록
- 저장은 임시 파일에 먼저 쓰고 이름을 바꾸는 방식이라, 저장 도중 전원이 나가도
  기존 파일이 깨지지 않습니다.
- 5분에 한 번 `workspace.json.bak` 로 백업합니다.
- 본 파일이 깨져 있으면 시작할 때 **자동으로 백업에서 되살리고**,
  깨진 파일은 `workspace.json.broken` 으로 남겨둡니다.

## 11. 자동 업데이트 (직원 배포용)

공유 폴더나 사내 웹서버 한 곳만 정하면 됩니다.

### 관리자 — 새 버전 배포
```powershell
# 1) 버전 올리기 (package.json 의 version)
# 2) 빌드
npm run dist
# 3) latest.json 생성 + 공유 폴더로 복사
npm run release -- --notes "표 기능 추가" --to "\\파일서버\공유\짱디터"
```

공유 폴더에는 이렇게 두 파일이 놓입니다.
```
\\파일서버\공유\짱디터\
    latest.json
    짱디터-1.2.0.exe
```

`latest.json` 은 이런 내용입니다(직접 만들어도 됩니다).
```json
{
  "version": "1.2.0",
  "file": "짱디터-1.2.0.exe",
  "notes": "표 기능 추가",
  "date": "2026-11-10"
}
```

### 직원 — 받는 쪽
☰ → **업데이트 설정…** 에서 그 폴더(또는 `https://...` 주소)를 한 번만 지정하면 끝입니다.
이후 시작할 때와 6시간마다 자동으로 확인하고, 새 버전이 있으면 상단에 띠가 뜹니다.
**업데이트** 를 누르면 내려받아 **자동으로 교체하고 다시 실행**됩니다.

> 처음 배포할 때 설정까지 대신 해두려면, 설정을 마친 PC 의
> `%APPDATA%\JJangditer\prefs.json` 에 들어 있는 `updateUrl` 값을 알려주면 됩니다.

웹서버를 쓸 경우 `latest.json` 과 exe 를 같은 경로에 올리고 `https://서버/경로` 를 지정하세요.

## 13. 자원 / 실행 속도

Electron(65MB)으로 만들었다가 **WebView2 + C# 으로 다시 만들었습니다.**

| | Electron 판 | 지금 (WebView2) |
|---|---|---|
| 파일 크기 | 65 MB | **1 MB** |
| 실행 시간 | 16 ~ 18 초 | **2.8 ~ 4 초** |
| 메모리 | 약 160 MB | 약 143 MB |
| 프로세스 | 5 개 | 1 개 + WebView2 |

Electron 판이 느렸던 이유는 단일 exe 가 **매번 229MB 를 임시 폴더에 풀어냈기** 때문입니다.
지금은 exe 가 1MB 라 그 과정이 없습니다.

### 그래도 2~4초가 걸리는 이유

아무 기능 없는 **빈 창 하나짜리 6KB 프로그램**도 이 PC 에서 **1.7~2.3초** 걸립니다.
**AhnLab V3 + Windows Defender** 가 프로그램이 뜰 때마다 검사하기 때문이고,
이건 어떤 방식으로 만들어도 피할 수 없습니다.

그래서 **시작 프로그램 등록**을 권합니다 (`도구` 메뉴 → `윈도우 시작 시 자동 실행`).
부팅할 때 한 번만 뜨고 하루 종일 트레이에 상주하므로 실행 대기가 사라집니다.
`✕` 를 눌러도 트레이에 남고 `Alt+Shift+J` 로 즉시 꺼냅니다.

## 14. 구성

```
host/JJangditer.cs      창·트리거 띠·설정 저장·화면 파일 풀기 (C#)
host/AppContext.cs      도킹·자동 숨김·트레이·단축키·업데이트·JS 다리 (C#)
host/lib/               WebView2 SDK DLL 3개 (빌드할 때 자동으로 받음)

src/index.html          패널 화면 구조
src/styles.css          스타일 (다크/라이트)
src/renderer.js         체크리스트 로직 (탭·행·표·변수치환·드래그정렬)
src/templates.js        기본 템플릿 ← 자주 쓰는 절차를 여기에 추가
src/jj-bridge.js        화면 ↔ 호스트 통신 (Electron 일 때는 비활성)
src/doc.js              일반 글 편집기 + 열(블록) 편집

tools/build.js          빌드 (csc.exe 로 단일 exe 생성)
tools/make-icon.py      아이콘 생성기
tools/export-template.js 내장 템플릿을 .jjt 로 추출
tools/publish.js        배포 도우미 (latest.json 생성 + 공유 폴더 복사)
templates/              바로 불러올 수 있는 템플릿 파일들

main.js, preload.js, src/trigger.*   예전 Electron 판 (개발용으로만 남겨둠)
```

트리거 띠(9px)는 Electron 판에서는 별도의 투명 창이 필요했지만,
지금은 C# 으로 직접 그려서 창 하나만 더 쓰면 됩니다.

**자주 쓰는 절차를 기본 템플릿으로 넣으려면** `src/templates.js` 에 추가하고
`npm run dist` 로 다시 빌드하면 ＋ 탭 메뉴에 나타납니다.

빌드 없이 바로 쓰거나 동료에게 전달하려면 `.jjt` 파일로 뽑으세요.
```powershell
npm run template                  # 템플릿 목록
npm run template ubuntu-install   # templates\*.jjt 로 뽑아내기
```

## 15. 알아두면 좋은 점

- 같은 버전으로 다시 빌드해도 화면 수정이 반영됩니다(내용이 바뀌면 자동으로 다시 풉니다).
- `npm start`(Electron 개발 모드)를 VS Code 터미널에서 쓸 때는 `ELECTRON_RUN_AS_NODE`
  환경변수 때문에 실행이 안 될 수 있습니다. `$env:ELECTRON_RUN_AS_NODE=""` 를 먼저 입력하세요.
- 코드 서명이 없어 처음 실행 시 SmartScreen 경고가 나올 수 있습니다 → `추가 정보` → `실행`.
  직원 배포 시 매번 나오는 게 번거로우면 코드 서명 인증서(연 20~40만원대)가 필요합니다.
- 같은 PC 에서 두 번 실행하면 새 창이 뜨지 않고 기존 창이 앞으로 나옵니다.
- 제목줄 **✕** 또는 트레이 아이콘 우클릭 → `종료` 로 완전히 끕니다.
